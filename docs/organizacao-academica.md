# Organização acadêmica

Este repositório armazena trabalhos próprios, códigos, anotações autorais,
exercícios e documentação necessária para executar os projetos acadêmicos.

## Conteúdo permitido no GitHub

- Código-fonte produzido pelo estudante.
- Exercícios e atividades autorais.
- Anotações próprias em Markdown.
- Relatórios e trabalhos autorais.
- Arquivos de configuração necessários para executar projetos.
- Programas de ensino cuja publicação seja permitida.
- README com instruções de compilação, teste e execução.

## Conteúdo privado

O conteúdo abaixo deve ficar fora do repositório público:

- Livros, apostilas e cursos de terceiros.
- Slides e PDFs distribuídos pelos professores.
- Provas, notas e resultados pessoais.
- Documentos pessoais ou institucionais.
- Listas de presença e dados de outros alunos.
- Senhas, tokens, chaves e arquivos `.env`.
- Bancos de dados contendo informações pessoais.
- Trabalhos de grupo sem autorização dos participantes.

No Windows, esses materiais ficam em:

`C:\Faculdade-Privado\4-periodo`

## Estrutura recomendada por disciplina

    disciplina/
    ├── programa-de-ensino/
    ├── aulas/
    ├── atividades/
    ├── trabalhos/
    ├── projetos/
    └── resumos/

As pastas devem ser criadas conforme forem necessárias. Não é obrigatório
manter diretórios vazios.

## Nomeação das aulas

Formato recomendado:

`AAAA-MM-DD-aula-NN-topico.md`

Exemplo:

`2026-08-03-aula-01-introducao-banco-de-dados.md`

## Projetos

Projetos maiores devem possuir um `README.md` próprio contendo:

1. Objetivo.
2. Dependências.
3. Como compilar ou instalar.
4. Como executar.
5. Como testar.
6. Autores e divisão de tarefas, quando for trabalho em grupo.
